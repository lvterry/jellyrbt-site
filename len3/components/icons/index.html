Icons

The icon instances used across the Len3 library.

Icon library

Use Phosphor Regular for shared product icons. Most controls use 16px icons; XS controls and badges use 12px. Calendar and Clock are the right-icon additions for Input.

Usage

Pair unfamiliar icons with a visible label. Label the action, not the drawing, for icon-only controls: “Remove report” instead of “Trash”. Decorative glyphs next to copy should not be announced.
