Icon Button

Perform a familiar action in a compact space.

Preview

Live preview
Figma specimen Web preview only

Usage

Use an Icon Button for a recognizable, repeated action. Use a labeled Button if the icon does not carry the meaning on its own. Always supply an accessible name.

Square sizes: 24, 28, 34 and 40px. Icons are 12px at XS and 16px otherwise. Increase the hit area separately on touch.
