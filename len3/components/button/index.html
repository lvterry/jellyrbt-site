Button

Trigger an action with a visible label.

Preview

Live preview
Figma specimen Web preview only

Usage

Use Default for the main action, Destructive for removal, Outline or Secondary for alternatives, and Ghost for quiet toolbar actions. Use Link styling for inline navigation, rendered as an anchor.

Sizes XS, SM, Default and LG are 24, 28, 34 and 40px tall. All have an 8px radius. The Outline variant uses the Control shadow.
